This project explores how language models can support semantics-aware process mining. It focuses on identifying anomalies in process flows and predicting the next activity.

## Implementation

- Built an evaluation environment for semantics-aware process mining tasks.
- Studied anomaly detection and next-activity prediction.
- Compared Llama, Mistral, and RoBERTa experimentally.
- Used fine-tuning and in-context learning to investigate different adaptation methods.

## Research question

How can language models help interpret process flows? The evaluation environment lets us compare models and adaptation methods experimentally and assess their suitability for both tasks.

## Technologies

Python, Hugging Face Trainer, Llama, Mistral, RoBERTa, LLM fine-tuning, and process mining.
